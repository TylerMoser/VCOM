# poke_h: outdoor stairs

Repeated front and oblique four-step field flights share one family with rotations. Farmhouse upper-floor stair is already part of its building.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeH_FieldStairs

Four-step field terrace flight; side-facing field copies reuse this geometry rotated. Canvas: 24 × 48 × 32 voxels. Rise: 16 voxels; 4 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [157, 69, 215, 104].
