# poke_k: outdoor stairs

Three matching flights share one family. Corrected calibration: 29.4 displayed pixels span a two-tile tree repeat, hence about 14.72 pixels per tile.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeK_LakesideStairs

Three repeated flights. Tree repeats are two tiles across: 29.4 displayed pixels = two tiles, correcting the older tree note for this collection. Canvas: 40 × 64 × 48 voxels. Rise: 32 voxels; 8 visible treads. Source calibration: 14.72 displayed pixels/tile. Crop: [42, 385, 104, 431].
