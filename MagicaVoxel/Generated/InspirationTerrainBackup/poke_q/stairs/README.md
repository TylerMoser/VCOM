# poke_q: outdoor stairs

Short summit and longer lower flights kept distinct, with tan wood treads and segmented green bamboo edging. Existing skull/chain/bamboo fence props excluded.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeQ_SummitBambooStairs

Four broad timber treads with green segmented bamboo edging below the summit. Canvas: 40 × 48 × 32 voxels. Rise: 16 voxels; 4 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [288, 120, 339, 164].
