# poke_g: outdoor stairs

Front and side flights have different visible tread counts. Building entrance steps remain in buildings.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeG_TerraceStairs

Six pale treads and golden timber edging at the town upper terrace. Canvas: 40 × 48 × 48 voxels. Rise: 24 voxels; 6 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [414, 266, 468, 308].
