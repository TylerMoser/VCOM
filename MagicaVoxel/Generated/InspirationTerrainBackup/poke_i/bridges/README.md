# poke_i.jpg: complete bridges

Three distinct crossings: bowed railed, shorter flat railed, and narrow unrailed. Uses newer building scale calibration of 9.5 displayed pixels/tile.

## PokeI_ArchedTimberBridge

Upper west river crossing: shallow bowed timber deck with pale close-spaced rails. Uses later building calibration of 9.5 displayed pixels/tile.

Canvas XYZ: 80 × 64 × 64; bank deck elevation: 24 voxels. Source tile estimate: 9.5 displayed pixels. Source crop: [253, 314, 310, 357].
