# poke_i: outdoor stairs

All visible terrain flights use the short farm family with rotations. Calibration follows newer buildings, not early tree records.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeI_FarmStairs

Repeated short flights; uses the newer building calibration of 9.5 displayed pixels per tile. Canvas: 24 × 48 × 32 voxels. Rise: 16 voxels; 4 visible treads. Source calibration: 9.5 displayed pixels/tile. Crop: [317, 223, 354, 249].
