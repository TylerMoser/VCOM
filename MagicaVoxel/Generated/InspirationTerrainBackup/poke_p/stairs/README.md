# poke_p: outdoor stairs

Side-on gray stair beside the lower bridge gets its own flight. The bridge remains unchanged.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeP_GullyStairs

Gray side-on terrain stair with orange-brown stringers beside the lower plank bridge. Distinct from the bridge. Canvas: 40 × 48 × 48 voxels. Rise: 32 voxels; 8 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [698, 928, 745, 994].
