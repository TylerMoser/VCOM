# poke_p.png: complete bridges

Two identical east-west crossings reuse the longer model; north-south shorter crossing uses the shorter model, rotated. Gray diagonal ramp is terrain stairs.

[Collection rules and validation](../../bridges/README.md)


## PokeP_GullyPlankBridge

Repeated east-west gully crossings: six-tile deck plus bank-anchor margin, three independent-looking posts at each corner; no connecting rails.

Canvas XYZ: 144 × 64 × 64; bank deck elevation: 40 voxels. Source tile estimate: 16 displayed pixels. Source crop: [646, 394, 794, 495].
