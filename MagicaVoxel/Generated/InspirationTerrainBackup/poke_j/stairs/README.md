# poke_j: outdoor stairs

Two repeated forest stair sprites share one family.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeJ_ForestStairs

Both forest flights share eight gray treads. Scale follows the building calibration. Canvas: 40 × 64 × 48 voxels. Rise: 32 voxels; 8 visible treads. Source calibration: 12.25 displayed pixels/tile. Crop: [158, 201, 210, 237].
