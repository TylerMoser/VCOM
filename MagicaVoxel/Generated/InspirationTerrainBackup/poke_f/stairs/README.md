# poke_f: outdoor stairs

Northern clipped stair uses the tall flight. Clinic entry is already included in its building. Pond slats belong to bridges.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeF_TallTerraceStairs

Eight silver-gray treads with red-brown stringers; northern clipped copy reuses this family. Canvas: 40 × 64 × 48 voxels. Rise: 32 voxels; 8 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [198, 70, 266, 115].
