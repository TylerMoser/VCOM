# poke_d.png: complete bridges

Three true spans: long four-arch river bridge, short southern river bridge, eastern road overpass. Lower eastern stair platform is terrain, excluded.

[Collection rules and validation](../../bridges/README.md)


## PokeD_FourArchBridge

Four long arches, broad cobbled carriageway, pale solid parapets and rounded pier noses; complete 20-tile scene in one file with two internal halves.

Canvas XYZ: 320 × 80 × 96; bank deck elevation: 64 voxels. Source tile estimate: 16 displayed pixels. Source crop: [142, 217, 465, 357].
