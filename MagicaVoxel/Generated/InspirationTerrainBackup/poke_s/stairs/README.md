# poke_s: outdoor stairs

Repeated six-step terrain flights and short eastern three-step flight covered. Central temple steps and smaller sanctuary steps already belong to the ruins collection, especially PokeS_RuinsSteppedSanctuary.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeS_MossyTerrainStairs

Repeated six-step outdoor rock cuts, outside the already authored sanctuaries. Low rough shoulders with restrained moss. Canvas: 40 × 48 × 48 voxels. Rise: 32 voxels; 6 visible treads. Source calibration: 10 displayed pixels/tile. Crop: [415, 435, 452, 469].
