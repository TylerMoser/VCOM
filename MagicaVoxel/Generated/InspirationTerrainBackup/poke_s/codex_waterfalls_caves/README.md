# poke_s: Codex waterfalls and cave entrances

Nine waterfall lengths/widths cover bounded garden drops and longer island drops. Repeated appearances reuse families. Visible vertical extents guide lengths; obscured terminations are inferred. Cloud gaps and temple recesses are not cave mouths.

[Shared collection rules, placement and validation](../../codex_waterfalls_caves/README.md). Complete VOX files are in the parent image folder. `Codex` in the family name distinguishes this batch from other authors.
