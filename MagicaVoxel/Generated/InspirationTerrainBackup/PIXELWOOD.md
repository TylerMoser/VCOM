A and C are JPEGs; B is a five-frame GIF whose modeled tree crops remain identical in every frame. Approximate enlargement is 3x in A/C and 5x in B. Size is based on underlying art pixels, using 16 voxels per source tile. Broadleaf, conifer and white-barked trees retain their distinct silhouettes. Bright and muted colorways are separate appearance families, not additional claimed species. Stumps are included as tree remnants; the stump two-color split is cut end grain versus bark, not foliage versus wood.

Duplicate decisions use source silhouette, leaf arrangements, colorway and relative tile dimensions, allowing for compression, clipping and scale. They are visual artwork matches, not claims of identical source-file bytes. Both generated folders contain reproducible local sculptors, manifests, source crops, current importer copies, audits and matched-light render evidence. C retains reuse records rather than copied VOX files.

Future sessions should consult this index before generating another pixelwood family. Preserve the first-owner files and link reused models from later image folders. All outputs remain complete models; no per-cell files. Gameplay integration is separate from the completed whole-model import/render checks.
