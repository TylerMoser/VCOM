## PokeT_TubularRailBridge

Eight-tile timber crossing with rounded metal hoop rails. Northern/southern horizontal copies and the two vertical views reuse this model with rotations.

Canvas XYZ: 128 × 48 × 64; bank deck elevation: 32 voxels. Source tile estimate: 16 displayed pixels. Source crop: [541, 268, 677, 322].
