# poke_t: outdoor stairs

Repeated warm stone cave-bank flights use rotations of one family. Side-on depth is inferred from the shared tread/curb motif; no duplicate orientation exports.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeT_CaveStairs

Six warm stone treads with pale curbs; repeated cave-bank side views reuse rotations. No cave wall or mouth included. Canvas: 40 × 48 × 48 voxels. Rise: 24 voxels; 6 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [170, 487, 228, 534].
