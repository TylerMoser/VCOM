# poke_c: outdoor stairs

Four terrain-flight sizes retained. Door thresholds remain in buildings; bridge deck is covered by prior collections.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeC_VillageStairs

Six olive stone treads between brown edging at the western village center. Canvas: 40 × 48 × 48 voxels. Rise: 24 voxels; 6 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [100, 311, 151, 354].
