# poke_c: Codex waterfalls and cave entrances

Two different sizes: the upper five-band cascade and lower three-band cascade. Shallow shelves between bands are an inferred reconstruction.

[Shared collection rules, placement and validation](../../codex_waterfalls_caves/README.md). Complete VOX files are in the parent image folder. `Codex` in the family name distinguishes this batch from other authors.

## PokeC_Codex_FiveTierCascade

Wide upper five-band cascade interpreted as five shallow descending sheets linked by shelves.

Canvas: 128 × 64 × 96 voxels; 16 displayed pixels/tile. Source crop: [333, 154, 468, 245].

[Source](reference/PokeC_Codex_FiveTierCascade.png) · [All styles](PokeC_Codex_FiveTierCascade_variations.png) · [Cardinal and underside views](PokeC_Codex_FiveTierCascade_geometry.png)

Water width: 112 voxels; interpreted vertical drop: 80; tiers: 5; free island fall: False.
