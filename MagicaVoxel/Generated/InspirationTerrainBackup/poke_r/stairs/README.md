# poke_r: outdoor stairs

Northern and commercial-garden three-step flights share one family. House thresholds remain building details.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeR_GardenStairs

Three shallow pale treads; northern path and commercial garden reuse this family. Canvas: 24 × 48 × 32 voxels. Rise: 12 voxels; 3 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [430, 99, 485, 126].
