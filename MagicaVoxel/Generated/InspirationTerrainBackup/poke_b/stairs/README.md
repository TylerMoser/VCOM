# poke_b: outdoor stairs

House entrance stairs and cottage annex stairs are already in the buildings. Two outdoor flights differ in tread count.

All files live in the parent image output folder. Each family has Base and all six established variations. [Shared collection rules and QA](../../stairs/README.md).

## PokeB_LongTerraceStairs

Twelve narrow gray treads; brown stringers. Upper plaza flight. Canvas: 56 × 48 × 48 voxels. Rise: 32 voxels; 12 visible treads. Source calibration: 16 displayed pixels/tile. Crop: [140, 100, 195, 165].
