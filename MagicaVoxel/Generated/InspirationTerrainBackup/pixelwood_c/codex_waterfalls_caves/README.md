# pixelwood_c: Codex waterfalls and cave entrances

One broad curtain. Standing stone, chest, log bridge and earth banks excluded; existing assets remain reusable.

[Shared collection rules, placement and validation](../../codex_waterfalls_caves/README.md). Complete VOX files are in the parent image folder. `Codex` in the family name distinguishes this batch from other authors.

## PixelwoodC_Codex_CurtainWaterfall

Broad blue curtain with a lighter central ribbon and comb-shaped lip/foot foam. 48 displayed pixels per tile; no standing stone or chest included.

Canvas: 80 × 40 × 48 voxels; 48 displayed pixels/tile. Source crop: [254, 127, 477, 269].

Water width: 64 voxels; interpreted vertical drop: 32; tiers: 1; free island fall: False.
